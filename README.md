# Zavoz Craft Launcher

Официальный лаунчер сборки **Zavoz Craft** для Minecraft 1.21.1 (NeoForge).

## Скачать

[**ZavozLauncher-Setup-1.0.1.exe**](https://github.com/pykipyp123-prog/zavozcraft-launcher/releases/latest/download/ZavozLauncher-Setup-1.0.1.exe)

Установщик весит около 3,2 МБ. Отдельно скачивать Java или .NET не нужно.

## Установка

1. Скачайте установщик по ссылке выше.
2. Запустите его. Если Windows SmartScreen покажет предупреждение, нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. Если на компьютере нет .NET 9 Desktop Runtime, установщик сам скачает и установит его (около 58 МБ, может потребоваться подтверждение UAC).
4. После установки запустите **Zavoz Craft Launcher** с рабочего стола.
5. Введите ник, выберите количество ОЗУ и нажмите **«Играть»**.

Лаунчер сам скачает сборку, моды и Java. Миры, настройки и сохранения хранятся отдельно и не удаляются при обновлении.

## Требования

- Windows 10 или Windows 11 (64-бит)
- Интернет
- 6 ГБ ОЗУ минимум, рекомендуется 8 ГБ и больше
- Свободное место на диске: около 10 ГБ

## Обновления

Лаунчер проверяет обновления автоматически. Новые версии публикуются в разделе [Releases](https://github.com/pykipyp123-prog/zavozcraft-launcher/releases).

## Старым игрокам

Сборки, установленные из старых репозиториев `Stepan1411`, больше не обновляются автоматически. Один раз скачайте и установите новый лаунчер по ссылке выше — настройки и миры сохранятся.
