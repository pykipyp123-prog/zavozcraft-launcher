# Zavoz Craft Launcher

Официальный лаунчер сборки **Zavoz Craft** для Minecraft 1.21.1 (NeoForge).

## Скачать

[**ZavozLauncher-Setup-1.2.1.exe**](https://github.com/pykipyp123-prog/zavozcraft-launcher/releases/latest/download/ZavozLauncher-Setup-1.2.1.exe)

Установщик весит около 3,2 МБ. Лаунчер сам скачает сборку, Java и .NET — ничего вручную искать не нужно.

## Установка

1. Скачайте установщик по ссылке выше.
2. Запустите его. Если Windows SmartScreen покажет предупреждение, нажмите **Подробнее → Выполнить в любом случае**.
3. Если появится запрос на установку .NET 9 Desktop Runtime, установщик скачает и поставит его сам (около 58 МБ, может потребоваться подтверждение UAC).
4. После установки откройте **Zavoz Craft Launcher** с рабочего стола.
5. Укажите ник и пароль и нажмите **Играть**.

Сборка 1.2.0 — это 216 модов на Minecraft 1.21.1 / NeoForge 21.1.256. При первом запуске лаунчер скачает около 625 МБ модов и файлы игры. Java 21 ставится автоматически, отдельно качать её не нужно.

## Требования

- Windows 10 или Windows 11 (64-бит)
- Интернет
- 6 ГБ ОЗУ минимум, рекомендуется 8 ГБ и больше
- Около 10 ГБ свободного места на диске

## Обновления

Лаунчер проверяет обновления при запуске и сам предлагает установить новую версию. Скачать вручную можно на странице [Releases](https://github.com/pykipyp123-prog/zavozcraft-launcher/releases).

## Старые версии от Stepan1411

Сборки, установленные со старых лаунчеров `Stepan1411`, не обновятся автоматически. Удалите старый лаунчер и установите новый с этой страницы — сохранения в `%APPDATA%\.zavozcraft` останутся на месте.
